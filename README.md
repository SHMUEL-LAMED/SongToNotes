# SongToNotes

אתר שממיר שירים והקלטות לתווים ישירות בדפדפן. הקובץ אינו נשלח לשרת.

## מה כבר עובד

- העלאת MP3, WAV, OGG, FLAC, M4A ו־AAC
- זיהוי תווים פוליפוני בעזרת Spotify Basic Pitch
- מצב מנגינה ראשית או כל התווים
- תצוגת תווים רגילה, Piano Roll וטבלת תווים
- הורדת MIDI, MusicXML, ABC ו־CSV
- התאמת רגישות וקצב BPM
- עיצוב מלא בעברית והתאמה לטלפון
- פריסה אוטומטית ל־GitHub Pages

## הפעלה מקומית

```bash
npm install
npm run dev
```

## בניית גרסת ייצור

```bash
npm run build
npm run preview
```

## דיוק

המנוע עובד בצורה הטובה ביותר על שירה נקייה או כלי נגינה יחיד. בשיר מלא עם כמה כלים, תופים ושירה יחד ייתכן שיידרש תיקון ידני בתוכנת תווים כמו MuseScore. קובץ MusicXML מיועד בדיוק להמשך העריכה הזאת.

## פרטיות

כל ניתוח האודיו מתבצע במכשיר של המשתמש. אין העלאה של השיר לשרת ואין צורך במפתח API בצד הלקוח.
